## Description
This is a project I'm currently working on to reproduce the results in the recent paper RAPTOR: A Foundation Policy for Quadrotor Control. So far I have reproduced the training code in Isaac Lab and run system identification experiments on my own micro-quad. I'm holding off on the project for now to see if I can get access to a motion capture system or write the drivers for the optical flow sensor included with my quad.
